# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Vibe GNOME is an independent community directory for GNOME apps, Shell
extensions, and agent skills. Guides help people build and share their projects.

## Users

People discovering GNOME community projects and maintainers sharing their work.
This description is inferred from the existing About page and architecture docs.

## Capabilities and Constraints

Preserve the existing React Router application, static prerendering, and D1
catalog. Badge assets must work on external websites and in Markdown READMEs.
Vibe GNOME is not affiliated with or endorsed by the GNOME Foundation.

## Brand Commitments

Retain the Vibe GNOME name and supplied paw logo. The existing implementation
defines the visual identity; this task extends it with a listing badge and guide.

## Accessibility & Inclusion

Keep visible keyboard focus, reduced-motion support, mobile layouts, light/dark/
system themes, and all supported GNOME accents as required by AGENTS.md.

## Evidence on Hand

`docs/design/architecture.md`, `app/routes/about.tsx`, and `public/logo.svg`.
Product context above follows repository evidence; no new positioning is assumed.
