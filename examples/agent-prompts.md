# Agent prompt examples

The live, copyable versions are maintained in `app/lib/preferences.ts`.

## Choosing a prompt

- Use the **App** prompt for a standalone GTK 4 window, persistent content, or a
  tool that should work outside GNOME Shell.
- Use the **Extension** prompt for changes to the panel, overview, window
  behavior, or Shell session.

After pasting, add one sentence such as:

> I want a tiny app that keeps a searchable history of clipboard text without
> sending data off the device.

or:

> I want an extension that shows the active audio output in Quick Settings on
> GNOME 49.
