- [GNOME JavaScript extension guide](https://gjs.guide/extensions/) — current
  extension architecture and development workflow
- [GNOME Extensions](https://extensions.gnome.org/) — extension discovery and

- [Flatpak documentation](https://docs.flatpak.org/) — packaging and distribution
- [r/vibe_gnome](https://www.reddit.com/r/vibe_gnome/) — community discussion
