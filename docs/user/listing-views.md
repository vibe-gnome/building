# Listing views

App, extension, and skill detail pages show **Views** in their information panel.
The count totals visits to that listing's detail page. Reloading or coming back
later adds another view; browsing the directory does not. It is not a count of
unique visitors, installations, or recommendations.

Counts are shared across visitors and persist when the site is updated. They
start when the view-count feature is enabled; previous visits are not backfilled.
The counter stores no visitor identifiers. If the service cannot be reached,
the panel says **Unavailable** and the listing remains usable.
