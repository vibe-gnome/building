# Add a Vibe GNOME badge

For a project listed on Vibe GNOME, open **Add a badge** in the site footer or
visit `/guides/badge` from the Guides directory.

1. Enter your app or extension name and select the matching project. Each result
   shows its type and listing path so you can distinguish projects with the same
   name. Leave the name blank to link to the Vibe GNOME homepage instead.
2. Choose the light or dark version to suit your README or website.
3. Choose Markdown for a README, or HTML for a website, then select **Copy code**.
   If clipboard access is unavailable, the page selects the code for manual copy.
4. Paste it below your project title, alongside other badges, or in your website
   footer. Preview the result and save.

The badge image is hosted on `https://vibe-gnome.org`. The preview and generated
embed link directly to your selected project's listing. Changing the badge style
or embed format keeps that destination. Editing the name clears the previous
selection; select a result before copying again, or clear the name to use the
homepage. If projects cannot load, select **Try again**. Only published apps and
extensions appear in the lookup.

**Download SVG** saves the selected version if you prefer to host it yourself.
Keep its wording and proportions. The default size is 228 × 64 pixels. The badge
indicates a Vibe GNOME listing; it is not a GNOME Foundation endorsement.

See [copy-ready examples](../../examples/listing-badge.md).
