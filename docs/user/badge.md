# Add a Vibe GNOME badge

For a project listed on Vibe GNOME, open **Add a badge** in the site footer or
visit `/guides/badge` from the Guides directory.

1. Choose the light or dark version to suit your README or website.
2. Choose Markdown for a README, or HTML for a website, then select **Copy code**.
   If clipboard access is unavailable, the page selects the code for manual copy.
3. Paste it below your project title, alongside other badges, or in your website
   footer. Preview the result and save.

The badge image is hosted on `https://vibe-gnome.org`. The embed links to the home
page by default. To send visitors to your listing, replace only the link
destination with your listing URL. Keep the image URL unchanged.

**Download SVG** saves the selected version if you prefer to host it yourself.
Keep its wording and proportions. The default size is 228 × 64 pixels. The badge
indicates a Vibe GNOME listing; it is not a GNOME Foundation endorsement.

See [copy-ready examples](../../examples/listing-badge.md).
