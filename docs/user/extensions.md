# Extensions

Open `/extensions` to browse community GNOME Shell extensions. Search by name,
author, UUID, or tag; combine a category with a GNOME Shell version and choose
grid or list view. Filters are kept in the URL so a filtered catalog can be
bookmarked or shared.

Select an extension for its requirements, supported Shell versions, source,
and installation instructions. Compatibility reflects the author's metadata.
The website does not install extensions or control the running GNOME desktop.

"Submit extension" opens a GitHub issue form. To correct, update, report, or
remove a listing, use the GitHub issue links on its detail page.
GitHub sign-in is needed to submit the request. Maintainers review requests
before changing the published catalog.

The appearance menu uses the same light, dark, system, and GNOME accent
preferences as the guide.
